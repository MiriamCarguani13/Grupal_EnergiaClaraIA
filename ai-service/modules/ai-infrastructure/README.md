# ai-infrastructure

Modulo de adapters para la IA hibrida explicable.

Contiene:

- `InMemoryEnergyHistoryProviderAdapter`
- `DefaultEnergyAiEngineAdapter`
- `ManualAiServiceFactory`

Restricciones actuales:

- Sin Spring.
- Sin JPA.
- Sin SQL Server.
- Sin dependencias del backend principal.
- Sin endpoints.

Este modulo existe para probar la integracion hexagonal de IA antes de conectarla con EnergyOps real.
