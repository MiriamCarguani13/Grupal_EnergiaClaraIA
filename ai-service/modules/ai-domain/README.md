# ai-domain

Modulo de dominio puro para la IA hibrida explicable de EnergiaClara.

Contiene Java puro para calcular:

- baseline dinamico
- promedio movil
- desviacion estandar
- Z-Score
- desviacion porcentual
- score de anomalia
- severidad sugerida
- confianza
- explicacion dinamica
- recomendacion dinamica

Restricciones:

- Sin Spring.
- Sin JPA.
- Sin SQL Server.
- Sin dependencias del backend.
- Sin LLMs.
